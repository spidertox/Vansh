# Icon and font sources

**Brand marks** (Python, Node.js, Telegram, React, Vite, Tailwind CSS, JavaScript, Git, Android, GitHub, Instagram, Hugging Face) are the paths from
Simple Icons (https://simpleicons.org, CC0 1.0), read from the copy bundled with mkdocs-material at `material/templates/.icons/simple/`.
Trademarks belong to their owners. Termux has no Simple Icons entry, so it appears only as a text chip.

**Original drawings:** security shield, globe, gamepad, bot and phone line art, chevrons, lanyard and ID card.

**Fonts** (SIL Open Font License 1.1, texts in this folder): Isometra, JetBrains Mono, Noto Sans Devanagari.
Each SVG embeds only the glyphs it uses, as a base64 WOFF2 subset.
